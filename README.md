# 260 to 220 by Christmas

A 92-day diet and training plan (Sep 25 to Dec 25, 2026) with a built-in log for
morning weight, meals eaten, workouts done and daily notes.

Open `index.html` in any browser, or host it free with GitHub Pages.

Your log is stored in the browser you use (localStorage). It is not uploaded to
GitHub and does not sync between devices. Use **Download backup** regularly and
**Restore from backup** to move between devices.
